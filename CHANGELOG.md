# Registro de cambios

## 1.0.0 - 2026-06-14

### Funcionalidades

- Registro de nombre, teléfono y correo electrónico.
- Búsqueda de contactos por cualquiera de sus datos.
- Eliminación de contactos.
- Persistencia de información en el almacenamiento local.
- Diseño adaptable para escritorio y dispositivos móviles.

### Automatización

- Pruebas automáticas con Node.js.
- Validación de sintaxis en ramas y pull requests.
- Despliegue automático de `main` en GitHub Pages.
